# J人約會行程安排(新竹篇)

新竹縣市雙人約會活動推薦與行程整理工具。使用者先填雙方偏好，挑選活動提案，再自行確認地點、時間、費用與強度，由網頁整合及檢查。

## 操作

1. 認識彼此：填活動喜好、環境、互動方式、體力與節奏。
2. 挑選提案：在 10 類、40 個提案中安排 2–5 站；每站帶入行政區搜尋地圖。
3. 填寫細節：填入自己確認的數字，免費或沒有休息請填 0。
4. 約會總覽：查看整體約會評語、雙方契合分數、費用、時間軸、超支超時、夜景及負荷提醒。

可按「試玩示範」查看完整例子。示範地點與數字全部是假設，並非查證後的店家推薦。

## 開啟與部署

- 直接以瀏覽器開啟 index.html。
- 或上傳 index.html 至 GitHub 儲存庫根目錄，於 Settings → Pages 選 Deploy from a branch、main、/(root)。
- 不需要安裝套件、建置工具、API 金鑰或後端伺服器。
- CSS、JavaScript、原創向量插圖都內嵌於同一檔案；地圖搜尋另需網路。

## 推薦原則

個人契合分數 = 活動喜好 × 60% + 環境符合 × 25% + 互動方式符合 × 15%。

提案排序 = 雙方平均 × 50% + 較低一方 × 50%。

不參加直接排除；未知偏好不當普通。這些是本作品的設計規則，沒有以真實滿意度資料驗證，分數不是滿意機率。

整體約會評語依相同資料與固定規則產生，包含雙方偏好、時間與費用摘要，以及優先改善事項。已知衝突與缺漏會優先提示，不會只因契合分數高就判定可行。下載、複製及列印都包含評語。

## 資料範圍

費用、時間、交通與強度由使用者提供。系統不估價、不算道路距離、不查即時營業或路況。僅安排同一天，夜景須於 20:00 起開始。只計算第一站到最後一站，不含住家出發及返家交通。

草稿僅儲存在目前瀏覽器，可下載或複製文字留存。沒有遠端資料庫、分析追蹤或即時 AI 呼叫。點地圖連結會把搜尋字詞送到 Google。

本作品依實際需求討論，以 AI 協助完成規格、實作、檢查與修改，作為 Vibe Coding 課程作業。
